# Sunil Kumar Sharma - Portfolio

A modern, professional portfolio website showcasing my work as a Software Engineer and IoT Developer.

## 🚀 Features

- **Modern Design**: Clean, professional interface with a contemporary color scheme
- **Responsive Layout**: Optimized for all devices - desktop, tablet, and mobile
- **Interactive Elements**: Smooth animations, particle effects, and hover interactions
- **Dark Theme**: Sleek dark mode with indigo and cyan accents
- **Fast Loading**: Optimized performance with efficient animations
- **Professional Sections**:
  - About Me
  - Work Experience
  - Projects
  - Technical Skills
  - Education
  - Research Publications
  - Contact Information

## 🛠️ Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Custom CSS with modern design principles
- **Animations**: CSS animations and JavaScript-powered effects
- **Icons**: Font Awesome icons
- **Fonts**: Inter font family for modern typography
- **Particles**: Interactive particle background effects

## 🎨 Design Highlights

- **Color Palette**: Professional indigo (#6366f1) and cyan (#06b6d4) accents
- **Typography**: Clean, readable Inter font
- **Layout**: Card-based design with subtle shadows and borders
- **Interactions**: Smooth hover effects and transitions
- **Accessibility**: Proper contrast ratios and semantic HTML

## 📱 Responsive Design

The portfolio is fully responsive and provides an excellent user experience across:
- Desktop computers (1920px+)
- Tablets (768px - 1024px)
- Mobile devices (320px - 767px)

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Or run a local server: `python -m http.server 8000`
